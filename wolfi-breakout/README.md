# Wolfi Breakout

## Feautures
* 3 Levels
* Controller support
* Score counter (will be displayed in the console once the game is over)
* Auto-Tilt when the ball gets stuck

## Keybindings
Key | Binding
---|---
Left/Right arrow keys | move the padle
Left Thumbstick on a controller | move the paddle
Space | start the game; fire the ball
Bottom Gamepad button | start the game; fire the ball
T key | tilt the ball; give it a small random force
Right Gamepad button | tilt the ball; give it a small random force
